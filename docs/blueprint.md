# **App Name**: Integral Illusion

## Core Features:

- Function Input: Allows users to input a mathematical function (e.g., x^2, sin(x)). Basic error check included.
- Numerical Integration Methods: Calculates the definite integral of a function using Rectangle Rule, Trapezoidal Rule, Simpson's 1/3 Rule and Simpson's 3/8 Rule.
- Animated Visualization: Displays a graphical representation of the integrated function and the method being used to calculate the definite integral with an animation.
- Configuration Panel: User interface to adjust function limits (a, b), subinterval count (n), and the integration method; supports animation controls to start, pause and restart it.

## Style Guidelines:

- Primary color: A vibrant violet (#9400D3) to capture the essence of complex mathematical visualization. Its slight darkness enhances contrast on a light background.
- Background color: A very light, desaturated lavender (#F0E6EF), subtly tinted towards the primary hue for harmony.
- Accent color: A neon green (#39FF14), shifted slightly towards the analogous side of the color wheel, and distinct in both brightness and saturation to provide a strong, energetic highlight.
- Body and headline font: 'Inter', a grotesque-style sans-serif suitable for both headlines and body text.
- Modern icons sourced from lucide-react to represent actions and controls.
- Responsive layout with a prominent P5.js canvas as the central element.
- Subtle animations and transitions on all interactive elements to improve UX.
